# Changelog

## Chrome 3.0.4 — public preview

- Publishes the current implementation with independent MAIN, ISOLATED and worker bundles, cosmetic-policy exceptions and site compatibility rules.
- Preserves the latest popup diagnostics, parent-domain pause behavior and page-reload control while translating Chrome metadata/settings into four languages.
- Consolidates publication materials and Git history into the original repository folder.
- Keeps root-folder installation working without a build and adds Node-only Chrome/Safari ZIP packaging, checksums and manifest dependency checks.
- Adds repeatable installed-browser checks, localized popup previews and current installation/technical guides.
- Includes Safari 1.0.0 as a separately named development-source package. Real iPhone PiP and locked-screen playback remain unverified.

See [validation](VALIDATION.md) for evidence and limits. This is a preview, with no promise of complete ad removal. The prior `v3.0.0-preview.1` release remains available as history; its validation record is [archived](archive/VALIDATION-3.0.0.md).
