## Focus 1.3.3 immediate YouTube startup — 2026-10-08

- The fixed YouTube MAIN bundle now runs at `document_start`, installing anti-adblock, response and request hooks before media/UI. The isolated bootstrap checks successful startup and only falls back to file injection if missing. Safari enables immediate `eAFgAQ` request tagging; Chrome retains its conditional recovery.
