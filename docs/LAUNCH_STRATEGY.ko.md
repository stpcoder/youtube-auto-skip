# 공개 언어와 확산 전략

조사 기준일: 2026-10-08. **브라질 포르투갈어를 첫 공개 언어로, 인도네시아어를 두 번째 검증 시장으로 추천한다.** 영어는 국제 개발자의 설치·기여 경로를 유지한다. 이 순서는 시장 규모와 개발자 커뮤니티를 바탕으로 한 전략적 판단이며 바이럴 확률을 측정한 결과가 아니다.

## 경쟁 공백에 대한 결론

포르투갈어·인도네시아어 광고 차단 도구가 없다는 가설은 확인되지 않았다. [uBlock Origin 언어 카탈로그](https://github.com/gorhill/uBlock/tree/master/src/_locales)와 [AdGuard 언어 카탈로그](https://github.com/AdguardTeam/AdguardBrowserExtension/tree/master/Extension/_locales)에 두 언어가 있다. [EasyList의 공식 보충 목록](https://easylist.to/pages/other-supplementary-filter-lists-and-easylist-variants.html)에도 EasyList Portuguese와 ABPindo가 있다. [ABPindo](https://github.com/ABPindo/indonesianadblockrules)는 인도네시아·말레이시아 사이트를 위한 기존 프로젝트다.

현지 언어 README가 좋은 YouTube 전용 Chrome MV3 프로젝트의 공급이 충분한지는 이번 제한된 검색만으로 정량화할 수 없다. 검색 결과가 적다는 이유로 경쟁 부재를 주장하지 않는다. 다음 검증은 현지 테스터가 설치·권한 설명·오류 재현 안내를 쉽게 이해하는지, 기존 도구보다 도움이 되는 구체적 상황이 있는지 확인하는 것이다.

현재 제품의 설득 포인트는 한 저장소에서 설치 ZIP, 일반 차단, YouTube 전용 처리, 테스트, 공개된 한계를 함께 확인할 수 있다는 점이다. “100% 차단”, “감지 불가능”, “즉시 재생”, 검증하지 않은 속도 비교를 사용하지 않는다.

## GitHub Trending을 이해하는 방법

[Trending](https://github.com/trending)은 프로그래밍 언어 필터와 **Spoken Language** 필터를 별도로 제공한다. 포르투갈어 [보기](https://github.com/trending?spoken_language_code=pt)와 인도네시아어 [보기](https://github.com/trending?spoken_language_code=id)는 국가별 순위와 다르다. 이 저장소의 코드는 JavaScript이며 README의 자연어를 바꿔도 프로그래밍 언어가 바뀌지는 않는다.

GitHub는 README 언어 선택만으로 등재되는 규칙이나 확정 스타 임계치를 제공하지 않는다. 특정 시간에 스타 몇 개를 받으면 등재된다고 보장할 수 없다. 현지화는 독자의 이해와 공유를 돕는 수단이다. 첫 공개 시점에 실제 사용자 관심과 유용한 기여를 모으는 것을 목표로 한다.

## 공개 준비 상태와 다음 조건

현재 공개본은 원본 작업 폴더에서 관리하는 Chrome 3.0.4 시험판이다. 기존 별도 복사본의 준비 자료와 Git 이력을 원본으로 통합했다. 포르투갈어 README, 영어·인도네시아어·한국어 설치 안내, 네 언어의 확장 메타데이터·설정 팝업, 이슈 양식, 라이선스와 필터 출처, CI, 설치 ZIP을 준비했다. Safari 1.0.0 개발 소스도 저장소와 별도 개발용 ZIP에 포함하며, 개인 실사용 기록은 공개 패키지에 넣지 않는다.

본격적인 홍보 전에 Chrome 3.0.4 실제 설치본으로 브라질 데스크톱 사용자에게 첫 영상·다음 영상·뒤로가기·탐색·광고 fallback·설정 토글을 확인받는다. 현재 YouTube 끊김 안내 숨김은 한국어 문구만 대상으로 하므로 포르투갈어 안내 숨김이 구현됐다고 소개하지 않는다. 지역 사이트 필터를 추가하려면 기존 규칙 한도, 출처, 라이선스와 회귀 검증을 함께 갱신한다.

처음 10~20명에게 설치 과정을 검증받고 반복되는 문제를 먼저 고친다. 이 숫자는 실행 목표이며 확보했다고 주장하는 사용자 수가 아니다. 포르투갈어 문구도 현지 개발자의 검토를 받으면 좋다.

DEV의 포르투갈어 글과 현지 개발자 커뮤니티는 각 채널 규칙을 확인한 뒤 후속 채널로 검토한다. 인도네시아는 현지 개발자 커뮤니티의 공유 규칙과 설치 가능 사용자를 먼저 확인한다.

공개 시각의 초기 가설은 브라질 평일 낮이다. 브라질리아 12:00~14:00는 한국 다음 날 00:00~02:00에 해당한다. 이 시간대가 바이럴에 최적이라고 검증된 것은 아니며, 게시 후 문제에 답할 수 있는 시간을 우선한다.

## 데모 구성

실제 화면으로 ① 설치 ZIP을 푼 뒤 확장을 로드하는 모습, ② 일반 사이트의 광고 차단과 사이트 예외, ③ YouTube 최초 진입·영상 전환, ④ 포르투갈어 설정 팝업을 짧게 보여준다. 프로필 이름·추천 영상·비공개 탭을 가리고, 관측된 광고·대기만 설명한다. 아직 촬영하지 않은 데모를 README에 성공 증거로 붙이지 않는다.

## 성과 판단

GitHub의 실제 저장소 방문·고유 방문·clone 추이, 설치 ZIP 다운로드, 재현 가능한 이슈, 번역·필터·코드 기여를 함께 본다. ZIP 다운로드는 설치나 활성 사용자 수가 아니고, clone은 사용 성공을 뜻하지 않는다. 확장에 사용자 추적 코드를 추가할 필요는 없다. 첫 주에 반복 설치 실패가 많으면 더 큰 홍보보다 문제 해결이 우선이다.

이 문서의 채널과 일정은 제안이다. 커뮤니티 글 게시, 개인 메시지 발송, 홍보 캠페인은 아직 실행하지 않았다.
